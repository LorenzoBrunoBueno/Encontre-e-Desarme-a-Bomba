# Encontre e Desarme a Bomba

Projeto acadêmico desenvolvido para o curso de Análise e Desenvolvimento de Sistemas do Senac Joinville.

## Sobre o projeto

Operação Zero é um jogo de realidade virtual no qual o jogador deverá encontrar e desarmar uma bomba antes que o tempo termine.

O jogador deverá explorar o ambiente, encontrar objetos, interagir com elementos do cenário e resolver desafios para conseguir concluir a missão.

O projeto terá uma versão para navegador convencional e uma versão utilizando realidade virtual por meio do WebXR, com suporte ao Meta Quest 3.

## Equipe

* Jean
* Lucas
* Lorenzo
* Luis

## Tecnologias

* HTML
* CSS
* JavaScript
* Three.js
* WebXR
* API
* Banco de dados
* Git e GitHub

## Objetivos

* Desenvolver um jogo web interativo;
* Criar um ambiente tridimensional;
* Implementar desafios e interações;
* Implementar sistema de pontuação;
* Desenvolver uma API;
* Utilizar banco de dados para persistência das informações;
* Disponibilizar uma experiência em realidade virtual;
* Realizar testes e documentar o projeto.

## Execução

As instruções de instalação, configuração e execução serão adicionadas conforme o desenvolvimento do projeto.

## Versão VR

O jogo contará com suporte ao modo WebXR para utilização no Meta Quest 3.

As instruções de acesso e utilização do modo VR serão adicionadas posteriormente.

## Documentação

A documentação completa do projeto será adicionada durante as etapas de desenvolvimento.

Projeto acadêmico — ADS Senac Joinville.
